# رياضيات الخامس الابتدائي (MATH)

تطبيق ويب (PWA) تفاعلي لمنهج الرياضيات للصف الخامس الابتدائي – العراق (الطبعة السادسة 2025).

- 10 فصول و49 درساً بحسب فهرس الكتاب، لكل درس ملخص ومثال محلول مع رقم الصفحة في الكتاب.
- أسئلة تدريب تتجدد أرقامها في كل مرة، مع تفسير فوري للإجابة.
- اختبار لكل فصل، و«التحدي الكبير» من 20 سؤالاً، ونظام نجوم يُحفظ على الجهاز.
- يعمل دون إنترنت بعد أول فتح، وقابل للتحويل إلى تطبيق أندرويد عبر PWABuilder.

التشغيل: افتح `index.html` أو فعّل GitHub Pages من إعدادات المستودع.
